# 2026 Market Skill Targets

This project is designed around current junior Data Analyst, Business Analyst, BI Analyst, and junior Analytics Engineering signals.

## What Entry-Level/Juniors Are Being Asked To Prove

### Core Technical Skills

- SQL: joins, CTEs, window functions, date logic, aggregation, subqueries, query performance awareness.
- Excel: pivots, lookups, formulas, Power Query, basic modeling, reconciliation.
- Python: Pandas, NumPy, data cleaning, EDA, automation, validation, light forecasting or segmentation.
- Power BI: data modeling, Power Query, DAX measures, dashboard design, row-level security, refresh/deployment.
- Cloud warehouses: BigQuery, Snowflake, SQL Server, Microsoft Fabric, or similar.
- Data modeling: fact/dimension tables, metric definitions, grain, relationships, data lineage.
- Data quality: missing/duplicate/incorrect records, validations, reconciliation, issue investigation.

### Business and Communication Skills

- Translate ambiguous stakeholder questions into measurable KPIs.
- Explain insights in plain business language.
- Document report logic, data definitions, assumptions, and limitations.
- Troubleshoot why numbers do not match across reports.
- Present recommendations, not just charts.
- Work with business, data, engineering, and leadership stakeholders.

### BA-Specific Skills

- Problem briefs and business cases.
- Current-state and future-state process maps.
- User stories and acceptance criteria.
- Requirements traceability.
- UAT test cases.
- Gap analysis and change impact notes.

### Differentiator Skills

- dbt models, tests, and documentation.
- Big data querying with BigQuery and PySpark.
- Snowflake exposure.
- Basic cloud deployment evidence.
- AI-assisted analysis workflow, documented responsibly.
- Domain fluency across retail, finance, healthcare, and operations.

## Project Strategy

Build fewer, deeper artifacts:

1. One cloud-first analytics platform.
2. Multiple domain case studies inside that platform.
3. One Power BI executive suite.
4. A strong BA documentation pack.
5. A resume/interview narrative that maps each artifact to job requirements.

The hiring signal should be: "I can do the actual job, from ambiguous business question to trusted dashboard and recommendation."
